## Sprint 2B (this pass): M6 colour Doppler and perineural cue

**Why Gemini's ultrasound shader was not swapped in.**
- M6 already computes B-mode from the real BodyParts3D meshes: the beam plane slices the actual clavicle, rib, artery and vein.
- That engine already has R = ((Z2−Z1)/(Z2+Z1))², attenuation in dB/cm/MHz, Rayleigh speckle, A-lines and specular needle anisotropy.
- The handoff shader works on schematic shapes at invented coordinates and uses a non-squared reflection coefficient.
- Swapping it in would lose the real anatomy, so only the new ideas were ported.
- The +0.35 bias and the fixed march step do not apply: the existing engine marches one row per pixel with no bias.

| Item | What was done |
|---|---|
| Colour Doppler | Pass in `ultrasoundSim.ts`. Only the beam component is shown: v_beam = −v·d, i.e. v·cos θ. Exactly 0 at tilt 0 (short axis, θ = 90°), so the screen says "no colour, tilt the probe". Wall filter at 4 % of the scale. Colour box drawn. BART map (red toward, blue away) with a colour bar and no velocity numbers. Slower near the vessel wall. Pulsatile artery, synced to the existing pulse; slow phasic vein flowing the opposite way. Flow direction is computed at runtime: lateral = away from the carotid. A "beam / artery-axis angle" readout is shown. Tilt range widened to ±15° |
| Perineural cue | Green bar when the tip is within 2 mm of a plexus trunk and no alarm is active. A second message appears when local anaesthetic spreads there. Always tagged "repère pédagogique, pas une garantie". Red alarms take priority |
| `toneMapped: false` | Set on the 3D beam-plane MeshBasicMaterial, which carries the live image and serves as the beam fan. The 2D display is a canvas, so ACES never touched it |
| Depth scale, illustrative tag | Already there: cm scale on the 2D image, and the "schématiques" credit line |
